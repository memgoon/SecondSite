# PTP1B molecular-dynamics workflow

These scripts implement the structure preparation, steered sampling, seed
selection and unrestrained simulations used for compound 2e. The protocol
follows the published inputs of Hardie et al., *Communications Chemistry*
6, 125 (2023), [doi:10.1038/s42004-023-00926-1](https://doi.org/10.1038/s42004-023-00926-1).

| Stage | Procedure | Entry point |
|---|---|---|
| H1 | Transfer the docked 2e pose into the published open and closed PTP1B constructs | `scripts/h1b_author_input.py` |
| H2 | Parameterize, solvate, minimize and equilibrate the starting systems | `scripts/h2b_gromacs_prep.sh` |
| H3 | Generate four-coordinate PLUMED restraints and run steered Amber simulations | `scripts/h3_plumed_input.py`, `scripts/h3b_amber_smd.sh` |
| H4 | Extract 100 equally time-spaced snapshots per direction, measure pocket contacts and export image-consistent coordinates | `scripts/h4c_seeds_author.py`, `ops/h3x_ligand_escape.py`, `ops/h4p_pose_report.py`, `ops/h4s_seed_strata.py`, `ops/h4x_image_export.py` |
| H5 | Re-solvate and equilibrate each selected seed, run 50 ns unrestrained MD and verify the solvent-stripped trajectory | `scripts/h5_seed_prep.sh`, `scripts/h5b_seeded_md.sh`, `scripts/h5v_verify.py` |

## Software and inputs

The calculation uses Amber 26 `pmemd.cuda`, AmberTools (`tleap`, `cpptraj`,
ParmEd and pytraj), GROMACS 2020.2, PLUMED 2.6.1, NumPy and SciPy. GROMACS is
used for preparation; Amber runs both steered and unrestrained simulations.
PLUMED must be available to the Amber steering executable. Install the engines
separately under their respective licenses. The runtime versions are recorded
in `ENVIRONMENT.txt`.

Retrieve the exact reference structures and steering templates with:

```bash
python md/fetch_reference_inputs.py
```

The download is pinned to AMMo commit
`51f406b291fa23d0414d09c34215f8407e23dd45` and checked against
`REFERENCE_INPUTS.json`. Its Apache-2.0 license is downloaded alongside the
reference files. `--local-ammo /path/to/AMMo` uses an existing copy.

Set `CANDIDATE_INPUT_DIR` to a directory containing
`2e_C1_A__open/` and `2e_C1_A__closed/`. Each contains the pose's
`protein_substrate_heavy.pdb`, GAFF2/AM1-BCC `ligand.mol2` and
`ligand.frcmod`. Set `PHOS` to the installed phosaa10 parameter directory,
containing `frcmod.phosaa10` and the PTR, SEP, TPO, Y1P, S1P and T1P libraries.
These are scientific inputs; they are not generated by substituting a new pose
or reassigning ligand charges during H5.

`SECONDSITE_MD_ROOT` selects the working root (default: this `md` directory).
It must contain `scripts/`, `ops/`, `mdp/` and the fetched `refs/` directory.
`AMMO_REFERENCE_DIR` can override the reference location. Add the engines to
`PATH`; `GMXRC`, `CPPTRAJ_BIN`, `PLUMED_BIN` and `PLUMED_KERNEL` can override
their locations. No SSH configuration or laboratory host names are required.

## Preparation and steering

```bash
python md/scripts/h1b_author_input.py
bash md/scripts/h2b_gromacs_prep.sh open 16
bash md/scripts/h2b_gromacs_prep.sh closed 16
bash md/scripts/h3b_amber_smd.sh --state open --prep md/prepared_gmx/2e__open --out md/open/production
bash md/scripts/h3b_amber_smd.sh --state closed --prep md/prepared_gmx/2e__closed --out md/closed/production
```

PTP1B residues 1–282 and the phosphotyrosine substrate are retained. Protein,
phosphate and ligand parameters use ff14SB, phosaa10 and GAFF2/AM1-BCC,
respectively, with TIP3P solvent, a 10 Å shell and neutralization plus 150 mM
NaCl. Preparation uses 7,500 minimization steps, 100 ps heating and 250 ps NPT
equilibration. The four steering coordinates describe the WPD loop, Tyr152
torsion, local stacking geometry and the Phe196–Phe280 distance. The executed
templates drive both directions for 150 ns followed by 2 ns restraint release.
Steering runs write restart and segment records for continuation with `--resume`.

## Seed selection and production

Run `h4c_seeds_author.py --run <production> --out <snapshots>` for each
completed direction, using its default `--mode authors`. This selects snapshots
at equal time intervals over the driven portion, following the published
notebook. Run the H4 contact and pose tools on these exact snapshots, then join
their records with `h4s_seed_strata.py --leg ... --json <strata.json>`.
Each tool provides argument details through `--help`.

With the directory layout above, `bash md/run_seed_selection.sh` runs these
steps for both completed steering directions and writes the selected seed list
to `md/audit/pocket.seeds`. Run it in a new analysis output layout: existing
snapshot exports are not overwritten.

The H5 input subset retains snapshots with at least one contact to the
compound-1 (FRJ) pocket under a 4.5 Å periodic minimum-image criterion.
Use `select_contact_seeds.py --strata <strata.json> --out <seeds.list>` to
record both retained and excluded seeds. In the current 2e run this retains
156 of the 200 snapshots: 56 from the open-start direction and 100 from the
closed-start direction. Selection uses the initial snapshot contacts, not
subsequent unrestrained outcomes. `h4x_image_export.py` exports coordinates for
H5 while verifying that imaging preserves intramolecular geometry and contacts.

For each retained seed:

```bash
bash md/scripts/h5_seed_prep.sh <seed-dir> <imaged-snapshot.pdb> <ligand.mol2> <ligand.frcmod> 16 --parent <parent-dry.prmtop>
bash md/scripts/h5b_seeded_md.sh --seed <seed-dir> --ns 50
```

H5 uses fresh initial velocities, a 2 fs step and 10 ps trajectory output.
The production runner writes a solvent-stripped trajectory and verifies its
topology, frame count and sampled coordinates against the wet trajectory
before removing the wet file. Input signatures prevent a completed short test
from being mistaken for a 50 ns run. Use `--check-only` to check an existing
seed without starting a simulation.

This directory contains the H1–H5 workflow. Subsequent trajectory-feature and
Markov-state analyses are maintained separately until their analysis protocol
is finalized.
